# 📊 量化持仓追踪与策略回测系统

基于 Streamlit 的轻量级投资组合管理工具，集成**实时行情**、**持仓盈亏监控**、**多策略量化回测**、**机器学习信号**以及**多语言支持**。引擎采用模块化设计，可切换 PyBroker 或 Backtrader，并支持经典规则策略与 LightGBM / CatBoost / XGBoost 集成投票策略。

## ✨ 功能特性

- **持仓管理**：添加、编辑、删除股票持仓，自动计算市值与盈亏。
- **实时行情**：一键通过 Yahoo Finance 刷新最新价格。
- **关注列表**：记录意向标的，设置目标买入价，自动计算差距。
- **交易记录**：卖出操作自动生成交易历史，统计累计收入与盈亏。
- **多策略量化回测**：
  - 经典技术指标：双均线交叉、布林带反转、MACD金叉死叉、RSI超买超卖。
  - 机器学习（LightGBM）与集成投票（LightGBM + CatBoost + XGBoost）。
- **动态交易信号**：根据选定策略，为每只持仓生成“买入/持有/卖出”信号及详细理由。
- **策略回测与可视化**：选择股票与策略，运行回测并查看收益曲线、夏普比率、最大回撤等。
- **模型管理**：支持重新训练 ML 模型并保存至本地，自动加载最新模型。
- **组合风险分析**：计算组合 Beta（vs SPY）及持仓相关性矩阵。
- **中文/英文界面切换**：侧边栏一键切换语言。
- **双引擎架构**：支持 Backtrader（推荐）和 PyBroker，引擎切换不影响策略代码。
- **数据本地存储**：持仓、关注列表、交易记录均保存在 JSON 文件中，无需数据库。
